# 사이트 구조 메모

사이트 공용 부분(뷰어·도구 패널·부록·앱 설치·배포)을 고칠 때 읽는 문서입니다.

## 사이트 구조 요점

- 뷰어 높이(2026-11-25): 휘쌤 휴대폰에서 '이미 사라진 세계'의 아래쪽(대사창)이 잘려 보였다(화면 전체를 쓰는 고정 배치라 처음 드러남 · 스크롤되는 실험은 티가 안 났음). 뷰어가 `100vh/100dvh` 로 높이를 잡았는데 그 휴대폰 브라우저에서는 실제로 보이는 높이보다 67px쯤 컸던 것으로 보임(**원인은 추정 · 내 환경에서는 재현 못 함 · 어느 브라우저인지 미확인**). 지금은 `body.viewer` 를 화면에 고정(`position:fixed`, 위·아래 0)하고 `lab.html` 머리의 스크립트가 `visualViewport.height` 로 한 번 더 맞춘다. `site.css` 링크에 `?v=` 를 붙였으니 **site.css 를 고치면 `index.html`·`lab.html` 의 `?v=` 값도 바꿀 것**(안 바꾸면 휴대폰에 옛 CSS 가 남는다). 또 잘린다고 하면: 이미 사라진 세계 설정 창 맨 아래의 '화면 W×H (창 w×h)' 숫자와 어느 브라우저·앱인지 물어볼 것.
- 뷰어의 휴대폰 머리줄(2026-11-24): 폭 720px 이하이거나 높이 560px 이하이면 `body.viewer` 에서 사이트 머리줄(`.top`)·과목 탭(`.mtabs`)을 숨기고 `.sub` 한 줄(뒤로 · 제목 · 도구 · 전체화면)만 남긴다(`--top-h:0`, 도구 버튼은 `.show-compact`). 실험이 하나뿐인 파일은 탭 줄(`.etabs`)도 접고, `experiments[]` 가 있는 파일(`.sub.multi`)만 탭 줄을 남긴다.
- 앱 설치(2026-11-24): `manifest.webmanifest`(이름 'V-Lab 가상 실험실', `display: standalone`, 시작 `./index.html`) + `assets/img/icons/`(192·512·마스크용 512·애플 180) 를 `index.html`·`lab.html` 머리에서 연결. 크롬 '앱 설치/홈 화면에 추가'가 되고 주소창 없이 열린다. **서비스 워커는 일부러 넣지 않음**(오프라인 저장을 하면 새로 올린 실험이 옛 화면으로 남는 문제가 생김 · 오프라인 요청이 오면 그때 '네트워크 우선' 방식으로).
- `index.html` 해시 라우팅, `lab.html` 뷰어는 iframe 으로 `file#exp=N&embed` 를 연다. 뷰어 탭 줄에는 같은 과목의 모든 실험이 번호 없이 한 줄로 나오고, 파일이 다른 실험을 누르면 그 파일로 이동한다.
- `assets/js/tools.js` 도구 패널: 환산 · 공학용 키패드 계산기(키보드 연동) · 과목별 부록(접이식, 색 점) 순서는 물리·화학·생명·지구·환경.
- 부록 자료는 `data/reference/<과목>.js`. '핵심 공식' 칸은 `type: "formula"` 로, 행은 `[이름, [식, 식…], 설명?]`. 식 표기: `\\frac{분자}{분모}` 분수, `\\sqrt{…}` 제곱근, `^{…}`·`^x` 위첨자, `_{…}`·`_x` 아래첨자 (JS 문자열 안이라 역슬래시 두 번). `tools.js` 의 `fmla()` 가 그림. 일반 표(`type: "table"`)에서는 " / " 가 줄바꿈으로 바뀌므로 공식을 일반 표에 넣지 않는다.
- `assets/js/site.js` 의 `VL.items(subject)` 가 등록부를 카드 단위로 펼친다.
- 화학 스마트 실험실의 가열·냉각은 실제 경과 시간 기준(가열 0.25 °C/s, 냉각 0.3 → 정체 8 s → 고체 0.45 °C/s). 사용자가 속도에 민감하니 바꾸기 전에 묻는다.
- 구조식 그리기: OpenChemLib 편집기는 CSS `zoom` 1.8배 + 포인터 좌표 보정 + `devicePixelRatio` 재정의(라이브러리 로드 **전**에 설정)로 크게 그린다. 자세한 사연은 파일 안 주석.
